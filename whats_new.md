**YOLO mode: when it's on, it really means it.**

YOLO would sometimes still stop and ask for permission even with the mode switched on for a chat — the auto-approve depended on matching each permission request back to your chat by a lookup that could quietly miss, and a miss meant a prompt slipped through.

Now the match is recorded at the source, the instant a turn starts, so every permission request in a YOLO chat is approved without asking — file edits, terminal commands, everything. Turn it on once for a chat and it stops interrupting you. Other chats keep asking like normal.
